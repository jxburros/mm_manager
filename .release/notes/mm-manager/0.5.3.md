# mmumblephone 0.5.3

## Changes

- Control panel settings stay put: mm_manager's options, the page you were on, the theme and hints are now also saved in the working folder (`.mm_gui/prefs/`) and read back when the page opens. They used to be lost when mm_gui moved to another port, the page was opened as `localhost` instead of `127.0.0.1`, or another browser was used. mm_manager's options are shared by the admins; the rest is each account's own.
- The SIP password survives a reload: it stays in that browser tab until the tab is closed, and is still never written to disk.
