# mmumblephone 0.4.0

## Changes

First steps towards Protel and Elcotel payphones, with a compatibility matrix that says exactly what each board supports (docs/compatibility.md).

- `mm_payphone.py` (Python 3, standard library only) adds a backend for each family besides the Nortel Millennium, which mm_manager handles as before.
- Protel: checks rate and option configurations against the ExpressNet manual, reads ExpressNet export files into the phone list, and explains ExpressNet communication errors. It cannot program or poll a Protel phone yet: the protocol is not public and has not been captured. docs/protel.md has what is known and the plan.
- Elcotel Series 5: reads, checks and writes R94 rate files, S94 speed dials and P94/P99 dialing patterns.
- Session captures for protocol research: import serial transcripts with their setup and outcome, and compare two sessions.

Nothing for Protel or Elcotel is verified on a physical phone yet.
