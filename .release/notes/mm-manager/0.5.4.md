# mmumblephone 0.5.4

## Changes

- Update center: the control panel can now update itself, under **manager → updates**. It lists the releases newer than the one you have and installs the one you pick. Updates only go forward: older versions aren't offered and mm_gui refuses to install them. Each package is checked against the release's `SHA256SUMS.txt` and the new version is test-run before anything is replaced; tables and config you may have edited are kept, and the control panel then restarts as the new version. On Windows installs made with the installer, it downloads and runs the new installer. This is the first version with the update center, so updating to it is done by hand.
- Releases build again on the current GitHub Linux runners. Their newer compiler and C library (GCC 15, glibc 2.43) warn about the bundled SQLite source, and warnings stopped the build. They no longer do for the bundled SQLite; mmumblephone's own code still has to build without warnings. 0.5.3 was never published because of this, so this release also carries its changes.
- Every pull request is now built, tested and packaged on Linux, macOS and Windows, so a break like that shows up before a release.
