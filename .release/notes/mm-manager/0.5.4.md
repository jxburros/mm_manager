# mmumblephone 0.5.4

## Changes

- Releases build again on the current GitHub Linux runners. Their newer compiler and C library (GCC 15, glibc 2.43) warn about the bundled SQLite source, and warnings stopped the build. Those warnings no longer stop the build for the bundled SQLite; mmumblephone's own code still has to build without warnings. 0.5.3 was never published because of this, so this release also carries its changes.
