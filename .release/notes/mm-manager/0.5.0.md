# mmumblephone 0.5.0

## Changes

Optional accounts for the control panel (`mm_gui`), so several people can share it.

- With no accounts, nothing changes: anyone at the computer running `mm_gui` can use all of it.
- An admin adds accounts under global → accounts. From then on everyone signs in. Admins can use everything. A user only sees the phones an admin assigns them, and on each phone only what the admin ticked: its overview, its records, and each group of settings. `mm_gui` checks this on every request.
- Passwords are stored as salted PBKDF2-SHA-256 hashes in `.mm_gui/accounts` in the working folder. Deleting that file turns accounts off again.
- `mm_gui -L 0.0.0.0` lets other computers sign in once an admin account exists. The connection is plain HTTP: use it only on a network you trust, or over a VPN or SSH tunnel.

Built and tested on Linux only so far.
